# 🩺 Шпаргалка участкового терапевта по назначениям и дозировкам

[![Лицензия](https://img.shields.io/badge/Лицензия-MIT-blue.svg)](LICENSE)
[![Клинические рекомендации](https://img.shields.io/badge/Клинические_рекомендации-МЗ_РФ_2024--2026-brightgreen.svg)](https://cr.minzdrav.gov.ru/)
[![Статус](https://img.shields.io/badge/Статус-Прототип_v1.0-orange.svg)](#)

Практическое клиническое руководство и интерактивная шпаргалка для **врачей-терапевтов участковых**, **врачей общей практики (семейных врачей)** и **ординаторов**. Составлено в строгом соответствии с актуальными Клиническими рекомендациями Минздрава РФ, РКО (Российского кардиологического общества), РГА (Российской гастроэнтерологической ассоциации) и РОИБ (Российского общества по изучению боли).

## 🚀 Возможности проекта

1. **⚡ Быстрый поиск на приеме:**
   - Международные непатентованные наименования (**МНН**) и популярные торговые названия в РФ.
   - Стартовые и максимальные суточные дозировки, кратность и длительность курсов.
   - Маркировка препаратов **1-й линии** (`⭐ 1-я Линия`) и препаратов резерва/симптоматических средств.
2. **🚨 Система «Красных флагов» (Red Flags):**
   - Симптомы тревоги, требующие неотложной помощи, вызова СМП или экстренной госпитализации.
3. **🧮 Интерактивные калькуляторы врача:**
   - **СКФ по формуле CKD-EPI (2021)** с автоматической рекомендацией по коррекции доз нефротоксичных препаратов (иАПФ, БРА, НПВП, антибиотики).
   - **Калькулятор пероральной регидратации (ВОЗ)** при острой диарее в зависимости от веса и степени обезвоживания.
   - **Расчет безопасных доз жаропонижающих** (парацетамол, ибупрофен).
4. **📋 Копирование назначений в МИС в 1 клик:**
   - Быстрый экспорт готового рецептурного шаблона для вставки в ЕМИАС, ПроМед, БАРС и др.
5. **🖨️ Адаптивная печать (Pocket Sheet):**
   - Специальный CSS-профиль для печати шпаргалки на бумагу в карманный формат халата врача.
6. **📱 PWA: установка как нативное приложение и офлайн-режим:**
   - `manifest.webmanifest` + Service Worker кэшируют приложение и все данные.
   - Устанавливается на домашний экран смартфона врача и работает **без подключения к сети**.
   - Тёмная тема, иконки, ярлыки быстрого доступа к кейсам и калькуляторам.
7. **🎯 Тренажер клинических сценариев:**
   - Интерактивный разбор 12 кейсов пациентов: оценка красных флагов, диагноз и **проверка назначений** с пояснением каждой ошибки.
   - Оценка по шагам, итоговый балл и сохранение лучшего результата на устройстве.

## 📌 Краткий справочник по нозологиям

### 1. ОРВИ и Грипп
- **Базис:** Обильное питье ($\ge 30$ мл/кг), солевые промывания носа, симптоматическая терапия.
- **Антибиотики:** ⛔ **Категорически не показаны** при неосложненном ОРВИ! Назначаются только при подтвержденных бактериальных осложнениях (вторая волна лихорадки, острый бактериальный риносинусит $> 10$ дней, пневмония).
- **Лихорадка/Боль:** Парацетамол 500–1000 мг (до 4 г/сут) или Ибупрофен 200–400 мг (до 1200 мг/сут без рецепта). *Аспирин лицам до 18 лет запрещен (синдром Рея)!*
- **Деконгестанты:** Ксилометазолин 0.1% или Оксиметазолин 0.05% строго **не более 3–5 дней** (риск медикаментозного ринита).
- **Грипп:** Осельтамивир 75 мг 2 р/сут — 5 дней (старт в первые 48 часов!).
- 🚨 **Красные флаги:** ЧДД $> 22$/мин, $\text{SpO}_2 < 95\%$, лихорадка $> 3\text{–}5$ дней, повторный скачок температуры, боль в груди при дыхании.

👉 [Подробный клинический протокол по ОРВИ](docs/01_orvi.md)

### 2. Артериальная гипертензия (АГ)
- **Целевое АД:**
  - 18–65 лет: **$120\text{–}129 / 70\text{–}79$ мм рт. ст.** (при хорошей переносимости).
  - $\ge 65$ лет или с ХБП: САД **$130\text{–}139$ мм рт. ст.**
  - ДАД не снижать ниже 70 мм рт. ст.!
- **Стратегия:** Старт с **двойной фиксированной комбинации в 1 таблетке**:
  - иАПФ или БРА + дигидропиридиновый АК (Периндоприл/Амлодипин, Телмисартан/Амлодипин) **ИЛИ**
  - иАПФ или БРА + тиазидоподобный диуретик (Периндоприл/Индапамид, Лозартан/ГХТ).
  - *Монотерапия:* только при АГ 1 ст низкого риска или у лиц старше 80 лет / «хрупких» пациентов.
- **Неосложненный криз:** Каптоприл 25 мг под язык или Моксонидин 0.2–0.4 мг внутрь. Снижение АД не более чем на 20–25% за первые 2 часа.
- 🚨 **Красные флаги:** Очаговый неврологический дефицит (инсульт), острая боль за грудиной (ОКС), удушье/хрипы (отек легких).

👉 [Подробный клинический протокол по АГ](docs/02_arterial_hypertension.md)

### 3. Дорсопатии (Боль в спине)
- **Режим:** 🛑 **Постельный режим более 48 ч строго не рекомендован!** Пациенту показано сохранение посильной повседневной активности.
- **Фармакотерапия:**
  - НПВП коротким курсом (5–14 дней) в минимальной эффективной дозе:
    - При гастрорисках: **Целекоксиб** 200 мг 1–2 р/сут + **ИПП** (Омепразол 20 мг).
    - При умеренном риске: **Мелоксикам** 7.5–15 мг 1 р/сут или **Нимесулид** 100 мг 2 р/сут.
  - Миорелаксанты: **Толперизон** 150 мг 3 р/сут (не седативит, разрешен водителям) или **Тизанидин** 2–4 мг на ночь.
  - Нейропатическая боль / радикулопатия: **Габапентин** с постепенной титрацией (300 мг $\rightarrow$ 900–1800 мг/сут).
- 🚨 **Красные флаги:** Синдром конского хвоста (задержка/недержание мочи, онимение промежности), прогрессирующий парез стопы («шлепающая стопа»), онкоанамнез + боли в покое, лихорадка со спондилодисцитом.

👉 [Подробный клинический протокол по дорсопатиям](docs/03_dorsopathy.md)

### 4. Хронический гастрит и диспепсия
- **Диагностика H. pylori:** $^{13}\text{C}$-уреазный дыхательный тест или моноклональный антиген в кале. *ИПП отменить за 14 дней, антибиотики и висмут — за 28 дней!*
- **Эрадикация H. pylori (1-я линия, 14 дней):**
  1. **ИПП** (Рабепразол 20 мг или Эзомепразол 20 мг) 2 р/сут за 30 мин до еды.
  2. **Амоксициллин** 1000 мг 2 р/сут после еды.
  3. **Кларитромицин** 500 мг 2 р/сут во время еды.
  4. **Висмута трикалия дицитрат** 240 мг 2 р/сут (или 120 мг 4 р/сут).
- **Симптоматическая терапия без H. pylori:**
  - При болях (EPS): ИПП 20 мг/сут (4–8 недель).
  - При тяжести и раннем насыщении (PDS): **Итоприда гидрохлорид** 50 мг 3 р/сут до еды (прокинетик, не удлиняет QT).
  - Купирование изжоги: Альгинаты (Гевискон) 10–20 мл после еды.
- 🚨 **Красные флаги:** Дисфагия, рвота «кофейной гущей», мелена, потеря веса, анемия, возраст дебюта $> 45\text{–}50$ лет $\rightarrow$ экстренная ФГДС.

### 5. Острая диарея у взрослых
- **ШАГ 1: Пероральная регидратация (БАЗИС ЛЕЧЕНИЯ!):**
  - Растворы ОРС пониженной осмолярности (*Регидрон Био*, *ОРС*, *Адиарин*).
  - Дробно по 50–100 мл каждые 10–15 минут. На каждый жидкий стул — дополнительно 150–250 мл раствора.
- **ШАГ 2: Энтеросорбенты:**
  - Смектит диоктаэдрический 3 г 3 р/сут или Полиметилсилоксан (Энтеросгель).
  - *Обязательный интервал 1.5–2 часа с любыми другими медикаментами!*
- **ШАГ 3: Биоэнтеросептики:**
  - *Saccharomyces boulardii* (Энтерол) 250–500 мг 2 р/сут (устойчив к антибиотикам, инактивирует токсины бактерий).
- **ШАГ 4: Кишечные антисептики (по показаниям):**
  - Рифаксимин 200 мг каждые 8 ч (курс 3 дня) — не всасывается в кровь.
- ⛔ **Предупреждение о Лоперамиде:**
  - **Категорически запрещен** при стуле с кровью, высокой лихорадке ($> 38.5^\circ\text{C}$) и подозрении на инвазивный/псевдомембранозный колит (риск токсического мегаколона и перфорации кишки)!
- 🚨 **Красные флаги:** Кровь в стуле, анурия/тяжелое обезвоживание, неукротимая рвота, диарея после антибиотикотерапии (*C. difficile*).

### 6. Сахарный диабет 2 типа
- **Диагноз:** HbA1c ≥ 6.5%, глюкоза натощак ≥ 7.0 ммоль/л или через 2 ч ОГТТ ≥ 11.1 ммоль/л.
- **Цель:** HbA1c < 7.0% для большинства; 7.5–8.0% — для пожилых и «хрупких».
- **Старт:** метформин 500 мг 1–2 р/сут с титрацией до 1000 мг 2 р/сут. При HbA1c на 1.5% выше цели — **стартовая двойная терапия** (метформин + SGLT2i/ГПП-1 РА).
- **Органопротекция:** при ССЗ, ХСН, ХБП, альбуминурии — SGLT2i или ГПП-1 РА независимо от HbA1c; статин; иАПФ/БРА при альбуминурии.
- 🚨 **Красные флаги:** ДКА/гиперосмолярное состояние, тяжелая гипогликемия, язва/некроз стопы, внезапная потеря зрения, безболевой ОКС.

👉 [Подробный клинический протокол по СД 2 типа](docs/06_diabetes.md)

### 7. ХОБЛ и бронхиальная астма
- **ХОБЛ:** постбронходилатационный ОФВ1/ФЖЕЛ < 0.70. База — отказ от курения, вакцинация, LABA + LAMA (группы B/E); ИГКС — при эозинофилах ≥ 300/мкл или частых обострениях.
- **Астма:** обратимость ОФВ1 ≥ 12% и ≥ 200 мл, вариабельность ПСВ > 10%. База — **ИГКС**; схема MART (ИГКС/формотерол «поддержка + по требованию»). ⛔ Монотерапия LABA запрещена.
- **Обострение:** сальбутамол, преднизолон 40 мг 5–7 дней, кислород (ХОБЛ SpO2 88–92%, астма 93–95%).
- 🚨 **Красные флаги:** «немое легкое», SpO2 < 90–92%, ЧДД > 30, ПСВ < 50%, спутанность, пневмоторакс.

👉 [Подробный клинический протокол по ХОБЛ и астме](docs/07_copd_asthma.md)

### 8. Цистит и инфекции мочевых путей
- **Неосложненный цистит:** нитрофурантоин 100 мг 2 р/сут **5 дней** или фосфомицин 3 г однократно. Фторхинолоны — резерв.
- **Пиелонефрит / осложненная ИМП:** посев мочи, цефтриаксон 1–2 г/сут 10–14 дней, инфузия, госпитализация; при обструкции — дренирование.
- **Асимптомная бактериурия:** лечить только при беременности и перед урологическими вмешательствами.
- 🚨 **Красные флаги:** лихорадка ≥ 38°C и боль в пояснице, рвота, гипотензия/тахикардия, макрогематурия, задержка мочи, мужчины/беременность/камни/катетер.

👉 [Подробный клинический протокол по ИМП](docs/08_uti.md)

### 9. Подагра
- **Острый приступ:** один противовоспалительный режим — напроксен 500 мг 2 р/сут, колхицин 0.5 мг 2–3 р/сут или преднизолон 30–35 мг 5 дней.
- **Уратснижающая терапия:** аллопуринол 100 мг (50 мг при ХБП) с титрацией до уратов < 360 мкмоль/л (< 300 при тофусах); прикрытие колхицином 3–6 мес.
- **Коррекция фона:** заменить тиазидный диуретик (лозартан), ограничить алкоголь и пурины.
- 🚨 **Красные флаги:** моноартрит + лихорадка (септический артрит!), почечная колика, ОПП, изъязвление тофуса, DRESS на аллопуринол.

## 🌐 Как запустить интерактивный прототип

### Вариант 1: Локально на компьютере (без установки)
Просто откройте файл `index.html` в любом браузере (Google Chrome, Safari, Yandex, Edge, Firefox). Он полностью автономен и работает без подключения к интернету.

### Вариант 2: Публикация на GitHub Pages (Бесплатный веб-сайт + PWA)
1. Создайте новый репозиторий на GitHub (например, `therapist-cheatsheet`).
2. Запушьте файлы в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "feat: initial prototype of therapist clinical cheatsheet"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/therapist-cheatsheet.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в:  
   **Settings** $\rightarrow$ **Pages** $\rightarrow$ **Branch: main** (папка `/root`) $\rightarrow$ нажмите **Save**.
4. Через 1–2 минуты ссылка вида `https://<ваш-логин>.github.io/therapist-cheatsheet/` будет доступна с любого смартфона или планшета!

### Установка на смартфон как приложение (PWA)
> Требуется HTTPS-адрес (например, GitHub Pages). При открытии файла `index.html` напрямую Service Worker недоступен.

- **Android / Chrome:** кнопка **«⬇️ Установить»** в шапке приложения или меню браузера $\rightarrow$ «Установить приложение».
- **iPhone / Safari:** кнопка «Поделиться» $\rightarrow$ **«На экран Домой»**.
- После установки приложение открывается в полноэкранном режиме, кэширует данные и работает **без интернета** (появляется индикатор офлайн-режима).
