# ХОБЛ и бронхиальная астма: Клинический протокол и назначения

> **Основание:** Клинические рекомендации МЗ РФ «Хроническая обструктивная болезнь легких» (2021–2024), «Бронхиальная астма» (2021–2024), GOLD 2024–2025, GINA 2024–2025.

---

## 1. Дифференциальная диагностика

| Признак | ХОБЛ | Бронхиальная астма |
| :--- | :--- | :--- |
| Возраст дебюта | Обычно > 40 лет | Часто детство/молодой возраст |
| Курение | Как правило, длительный стаж | Не обязательно |
| Симптомы | Постоянные, медленно прогрессируют | Вариабельные: ночь, утро, триггеры |
| Обратимость обструкции | Неполная | **ОФВ1 ≥ 12% и ≥ 200 мл** |
| Вариабельность ПСВ | Не выражена | **> 10%** |
| Атопия, эозинофилия | Может отсутствовать | Часто есть |
| Эффект ИГКС | Ограничен | Высокий |

**Спирометрия** — обязательна для обоих диагнозов. При ХОБЛ обструкция определяется по **постбронходилатационному ОФВ1/ФЖЕЛ < 0.70**.

### Классификация ХОБЛ (GOLD, по ОФВ1 после бронхолитика)

| Стадия | ОФВ1 |
| :--- | :--- |
| GOLD 1 | ≥ 80% |
| GOLD 2 | 50–79% |
| GOLD 3 | 30–49% |
| GOLD 4 | < 30% |

Группы **A / B / E** определяются по симптомам (mMRC, CAT) и числу обострений за год.

## 2. Терапия ХОБЛ (стабильный период)

**База для всех пациентов:**
- Полный **отказ от курения** (единственная мера, замедляющая падение ОФВ1).
- **Вакцинация** против гриппа (ежегодно), пневмококка, COVID-19.
- Легочная реабилитация, физическая активность, нутритивная поддержка.

**Бронходилататоры:**

| Группа | Препарат | Доза |
| :--- | :--- | :--- |
| SABA (по требованию) | Сальбутамол | 100 мкг 2–4 вдоха по потребности |
| SAMA | Ипратропия бромид | 20–40 мкг 3–4 р/сут |
| LAMA | Тиотропий | 18 мкг 1 р/сут (или 2.5 мкг Респимат) |
| LABA | Формотерол, салметерол | По инструкции, 2 р/сут |
| LABA + LAMA | Формотерол/гликопирроний, индакатерол/гликопирроний | 1–2 вдоха 2 р/сут |

- **Группа A:** один бронходилататор.
- **Группа B/E:** **LABA + LAMA** (двойная терапия) — приоритет.
- **ИГКС добавляют** при эозинофилах крови ≥ 300/мкл или частых обострениях: тройная терапия LABA + LAMA + ИГКС.
- **Муколитики** (N-ацетилцистеин, эрдостеин) — при вязкой мокроте, могут снижать частоту обострений.

> ИГКС **не применяются в виде монотерапии** при ХОБЛ.

## 3. Терапия бронхиальной астмы

**Цель:** контроль симптомов + предотвращение обострений.

| Ступень | База | Средство скорой помощи |
| :--- | :--- | :--- |
| 1 | ИГКС/формотерол **по потребности** | ИГКС/формотерол |
| 2 | Низкие дозы ИГКС ежедневно | Сальбутамол или ИГКС/формотерол |
| 3 | Низкие дозы ИГКС + LABA (или средние дозы ИГКС) | Сальбутамол / ИГКС-формотерол |
| 4 | Средние/высокие дозы ИГКС + LABA | То же |
| 5 | + тиотропий, биологические препараты, системные ГКС | То же |

**Основные препараты:**
- **Будесонид** 200–400 мкг/сут (низкие дозы) в 1–2 приема.
- **Будесонид/формотерол** 160/4.5 мкг — режим **MART** («поддержка + по требованию»).
- **Беклометазон, флутиказон** — альтернативы.
- **Сальбутамол** — reliever; **монтелукаст** — дополнительная опция.
- Обучить технике ингаляции, использовать спейсер, полоскать рот после ИГКС.

> **Монотерапия LABA при астме запрещена** — риск тяжелых обострений и летального исхода.

---

## 4. Обострения: неотложная помощь

**ХОБЛ:**
- Сальбутамол 2–4 вдоха каждые 20 мин × 3 (или небулайзер 2.5–5 мг), + ипратропий.
- **Преднизолон 40 мг** внутрь 5 дней.
- Кислород: целевая **SpO2 88–92%**.
- Антибиотик (амоксициллин/клавуланат, доксициклин) — при усилении одышки + увеличении объема и гнойности мокроты, 5–7 дней.
- НИВЛ при гиперкапнии/ацидозе; госпитализация при тяжелом обострении.

**Астма:**
- Сальбутамол многократно, кислород: целевая **SpO2 93–95%**.
- **Преднизолон 40–50 мг** внутрь 5–7 дней.
- При тяжелом приступе — ипратропий, при неэффективности — ГКС парентерально, госпитализация.

---

## 5. Красные флаги

- Невозможность говорить фразами, ЧДД > 30, ЧСС > 120, участие вспомогательной мускулатуры.
- SpO2 < 90–92%, цианоз, спутанность, сонливость.
- **«Немое легкое»** — резкое ослабление дыхательных шумов при нарастающей одышке.
- ПСВ < 50% от лучшего, отсутствие ответа на сальбутамол за 15–20 мин.
- Лихорадка с гнойной мокротой, боль в груди при дыхании, асимметрия дыхания (пневмоторакс).
- Истощение, отсутствие эффекта от лечения.

---

## 6. Мониторинг

- Спирометрия/ПСВ — по показаниям и при изменении терапии.
- Оценка контроля астмы (ACT) и симптомов ХОБЛ (CAT/mMRC) на каждом визите.
- Проверка техники ингаляции и приверженности — на каждом визите.
- Отказ от курения и вакцинация — повторять на каждом приеме.

---

> **Дисклеймер:** Протокол носит справочный характер. Выбор препаратов, доз и ступени терапии определяет лечащий врач с учетом фенотипа, функции легких, коморбидности и переносимости.
